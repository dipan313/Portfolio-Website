# Dipan Mazumder - Portfolio Ultimate

A premium, high-performance portfolio website built with **React**, **Vite**, and **Framer Motion**. This project showcases my journey as an AI/ML Engineer, highlighting my technical skills, hackathon achievements, and featured projects with a focus on cutting-edge aesthetics and interactive user experience.

---

## ✨ Key Features

- 🚀 **Lightning Fast**: Built with Vite for instant server start and lightning-fast HMR.
- 🎨 **Glassmorphism Design**: Modern, premium UI with smooth gradients and glass-like elements.
- 🖱️ **Interactive Aesthetics**:
  - **3D Hero Tilt**: Interactive hero image that responds to mouse movement.
  - **Spotlight Cards**: Mouse-tracking neon glow effectively highlighting every section.
  - **Custom Cursor**: Advanced physics-based trailing cursor for enhanced engagement.
- 📱 **Fully Responsive**: Optimized for all devices, from mobile to ultra-wide displays.
- ⚡ **Butter-Smooth Animations**: Powered by Framer Motion for elegant scroll reveals and transitions.
- ✉️ **Functional Contact Form**: Integrated with Web3Forms for seamless message delivery.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite 8
- **Animations**: Framer Motion
- **Icons**: Lucide-React
- **Styling**: Vanilla CSS with modern Flexbox/Grid layouts
- **Forms**: Web3Forms API

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (Latest LTS version recommended)
- [npm](https://www.npmjs.com/)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/dipan313/Portfolio-Website.git
   cd Portfolio-Website
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Contact Form**:
   Update your Web3Forms access key in `src/components/Contact.jsx`.

### Usage

**Run the development server**:
```bash
npm run dev
```

**Build for production**:
```bash
npm run build
```
